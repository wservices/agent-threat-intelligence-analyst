# 0.2.0 — tested script layer

Deepened the `threat-intelligence-analyst` profile from scaffold to a
script-backed role. All scripts are offline, read-only, side-effect-free
(no network/API calls — they operate on data the analyst has already exported),
Python 3.9+ stdlib-first with an `argparse` CLI and `main(argv=None) -> int`.

## Scripts added (`scripts/`)

- `ioc_normalize.py` — refang mixed report text, extract + classify + dedupe
  IOCs (IPv4, domain, URL, email, MD5/SHA1/SHA256), re-emit defanged JSON/CSV.
- `stix_ioc_extract.py` — summarize a STIX 2.x bundle: indicators (+ parsed
  pattern values), malware, attack-patterns (ATT&CK IDs), and resolved
  relationships.
- `attack_layer_build.py` — build a MITRE ATT&CK Navigator layer (v4.5) from
  technique IDs (+ optional scores); validates `Txxxx`/`Txxxx.yyy`, rejects
  malformed IDs, merges duplicates keeping the max score.
- `feed_dedup.py` — aggregate + dedupe + age-out indicators across JSON/CSV feed
  files: union sources, reconcile first_seen/last_seen, take max confidence,
  drop entries older than `--max-age-days`.
- `intel_report_build.py` — assemble a structured Markdown intel brief (exec
  summary, ATT&CK/TTP table, defanged IOC table, assessment, recommendations)
  from a findings YAML/JSON.

## Skills now script-backed

- `ioc-enrichment` → `ioc_normalize.py`
- `threat-feed-aggregation` → `feed_dedup.py` and `stix_ioc_extract.py`
- `adversary-ttp-mapping` → `attack_layer_build.py`
- `threat-intel-reporting` → `intel_report_build.py`
- `malware-campaign-tracking` → references `stix_ioc_extract.py`

Each skill's `## How to Run` and `## Verification` now invoke the bundled script
with a real runnable example. Added behavior-contract tests under `tests/`
(one file per script, 28 tests) exercising parsing, classification, validation,
dedup, age-out, and Markdown rendering; the scaffold smoke test is retained.
