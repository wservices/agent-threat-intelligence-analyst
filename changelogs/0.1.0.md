# 0.1.0 — initial scaffold

First scaffold release of the `threat-intelligence-analyst` Hermes profile.

- Role definition (`ROLE.md`), persona (`SOUL.md`), and distribution manifest
  (`distribution.yaml`) — research/advisory posture, read-only and passive by
  default, escalates to the Security Team Lead; never engages adversary
  infrastructure.
- Six bundled skills: `cve-and-advisory-tracking`, `adversary-ttp-mapping`,
  `ioc-enrichment`, `malware-campaign-tracking`, `threat-feed-aggregation`, and
  `threat-intel-reporting` (with a `templates/brief.md`).
- APT tool layer (`jq`, `ripgrep`, `curl`, `whois`, `dnsutils`; `python3` from the
  base image) — all read-only; no container capability required.
- Env manifest for key-gated OSINT/feed sources (VirusTotal, AbuseIPDB, Shodan,
  AlienVault OTX, MISP, NVD); generated `docs/ENVIRONMENT.md`.
- Offline pytest scaffold smoke test, GitLab CI include, and MIT license.

Standards referenced: MITRE ATT&CK, STIX/TAXII concepts, the Diamond Model.
